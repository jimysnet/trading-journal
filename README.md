# Ημερολόγιο Συναλλαγών

Κοινό ημερολόγιο συναλλαγών για την παρέα: καταγραφή trades, κανόνες ρίσκου, ημερήσιο check-in, αναλύσεις,
Μπούσουλας στρατηγικών, προπόνηση, ο Καθηγητής (AI), AI Bot με εικονικό κεφάλαιο, Εργαστήριο στρατηγικών και chat της παρέας.

## Δομή

| Φάκελος / αρχείο | Τι είναι |
|---|---|
| `src/index.html` | **Ο πηγαίος κώδικας.** Όλη η εφαρμογή σε ένα αρχείο (HTML + CSS + 3 μπλοκ JavaScript). Εδώ γίνονται οι αλλαγές. |
| `build.py` | Χτίζει το `dist/` από το `src/index.html` (`python3 build.py`). |
| `dist/` | Η έτοιμη σελίδα όπως δημοσιεύεται: `index.html`, `app.js`, `i18n.js`, `manual.js`, εικόνες. |
| `assets/` | Εικόνες του Καθηγητή. |
| `agent/` | Σενάρια που χρησιμοποιεί η καθημερινή προγραμματισμένη εργασία (κεριά αγορών, συλλογή δεδομένων). |
| `extras/` | Pine Script για TradingView και βοηθητικά αρχεία (επιπλέον κεφάλαια Μπούσουλα, τράπεζα ερωτήσεων). |
| `docs/` | Οδηγός χρήσης (PDF). |

## Πού τρέχει

Η σελίδα είναι φτιαγμένη για να τρέχει ως **Claude Artifact** στο claude.ai. Από εκεί παίρνει:

- `db`: κοινή αποθήκευση (συναλλαγές, chat, ρυθμίσεις)
- `user`: ποιος είναι συνδεδεμένος, ονόματα και φωτογραφίες
- `sample`: ο Καθηγητής (AI)
- `mcp`: τιμές αγορών από CoinGecko, Crypto.com, Gemini
- `assets` / `downloads`: εικόνες, αρχεία, εξαγωγές

Αν ανοίξεις το `dist/index.html` έξω από το claude.ai (π.χ. τοπικά ή σε GitHub Pages), δουλεύει σε **τοπική λειτουργία**:
οι εγγραφές μένουν μόνο στον browser σου και δεν υπάρχουν ο Καθηγητής, το κοινό chat ή οι ζωντανές τιμές.

## Ροή αλλαγών

1. Αλλαγή στο `src/index.html`
2. `python3 build.py`
3. Δημοσίευση του `dist/` στο artifact

Δεν αποθηκεύονται πουθενά κλειδιά ανταλλακτηρίων και η εφαρμογή δεν εκτελεί πραγματικές εντολές· το AI Bot είναι μόνο εικονικό (paper trading).
